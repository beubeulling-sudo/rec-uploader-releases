REC UPLOADER 개인정보처리방침

시행일: 2026년 10월 13일 · REC UPLOADER 안내·사용설명서 · 서비스 약관

REC UPLOADER(이하 "프로그램")는 사용자가 자기 PC에 저장된 방송 녹화 파일을 사용자 본인의 유튜브 채널에 올리도록 돕는 Windows 프로그램입니다. 프로그램은 사용자의 PC에서만 동작하며, 개발자가 운영하는 서버가 없습니다.

1. 이용하는 구글·유튜브 데이터

프로그램은 사용자가 구글 계정으로 로그인해 허용한 범위에서 YouTube API 서비스(YouTube Data API)를 이용합니다.

권한쓰는 곳
유튜브 동영상 업로드
youtube.upload		사용자가 고른 녹화 파일을 사용자 채널에 올립니다.
유튜브 계정 관리
youtube		채널 이름 확인, 썸네일 적용, 재생목록에 넣기, 공개 범위·제목 바꾸기, 올라간 영상 목록과 처리 상태·지역 차단 여부 보기, 사용자가 요청한 영상 삭제.

프로그램은 이 데이터를 위에 적은 기능에만 쓰며, 광고·분석·판매 등 다른 목적으로 쓰지 않습니다.

2. 저장하는 정보와 위치

  • 로그인 정보(구글 인증 토큰)와 업로드 기록·설정은 프로그램 폴더 안의 data 폴더, 즉 사용자 PC에만 저장됩니다.
  • 녹화 파일과 썸네일은 사용자가 고른 폴더에 그대로 있으며, 프로그램이 지우지 않습니다.
  • 개발자는 사용자의 토큰, 영상, 채널 정보, 업로드 기록을 받거나 볼 수 없습니다. 프로그램은 이 정보를 구글(유튜브) 외의 곳으로 보내지 않습니다.

3. 제3자 제공

프로그램은 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 영상과 관련 정보는 사용자의 요청에 따라 YouTube API 서비스를 통해 구글(유튜브)로만 전송됩니다.

4. 구글 서비스 약관

프로그램은 YouTube API 서비스를 사용합니다. 프로그램을 쓰면 다음에도 동의하는 것이 됩니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

프로그램이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

5. 권한 철회와 정보 삭제

  • 언제든 Google 계정 → 보안 → 서드 파티 연결(바로가기)에서 프로그램의 접근 권한을 철회할 수 있습니다.
  • 프로그램 설정의 "다른 계정으로 바꾸기"를 누르거나 프로그램 폴더의 data 폴더를 지우면 PC에 저장된 로그인 정보와 기록이 모두 삭제됩니다.

6. 문의

개인정보처리방침이나 프로그램에 관한 문의는 문의·개선 의견 양식으로 보내 주세요.

English summary

REC UPLOADER is a Windows desktop app that uploads recordings from the user's own PC to the user's own YouTube channel. It uses YouTube API Services with the youtube.upload and youtube scopes only to upload videos, apply thumbnails, add videos to playlists, change titles and privacy, list the user's uploads and their processing/region status, and delete videos at the user's request. OAuth tokens, settings and upload history are stored only on the user's PC (the app's data folder). The developer runs no server and never receives this data, and it is not shared with or sold to third parties. By using the app you agree to the YouTube Terms of Service and the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at Google security settings, and delete all local data by removing the app's data folder. Contact: contact form.
