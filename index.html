REC UPLOADER 사용설명서

방송이 끝나면 생기는 녹화 파일을 찾아, 썸네일과 함께 내 유튜브 채널에 올려 주는 Windows 프로그램이에요.

✓ 녹화가 끝나면 알아서 목록에파일을 찾아 고를 필요 없이, 썸네일 연결과 날짜 제목까지 자동이에요.
✓ 끊겨도 이어서 올려요웹에서 올리면 탭을 닫거나 인터넷이 끊길 때 처음부터 다시 해야 해요. 여기선 끊긴 곳부터 이어서 올려요.
✓ 방송 중엔 업로드를 멈춰요방송 화질을 지키고, 녹화가 끝나면 이어서 올려요.
✓ 올라간 뒤까지 확인해요유튜브 처리가 멈췄거나 한국에서 막힌 영상을 알려 주고, 다시 올리기도 돼요.
로그인 정보는 이 PC에만 저장돼요. 유튜브 로그인 정보와 기록은 프로그램 폴더의 data 안에만 있고, 다른 곳으로 보내지 않아요. 녹화 파일은 지우지 않아요.

1. 설치하기

  1. 프로그램 받기 — 배포 페이지에서 맨 위 버전의 rec-uploader_v….zip을 받아요.
  2. 압축 풀기 — 원하는 곳에 압축을 풀어요. 예: C:\REC UPLOADER
    바탕화면·문서처럼 OneDrive로 동기화되는 폴더는 피해 주세요. 동기화 중 파일이 잠겨 설치가 실패할 수 있어요.
  3. 설치하기.bat 더블클릭 — 검은 창이 열리고 필요한 것들을 자동으로 설치해요. 처음엔 몇 분 걸려요.
    "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 눌러요.
  4. 바탕화면 아이콘으로 실행 — 설치가 끝나면 바탕화면에 초록 아이콘 REC UPLOADER가 생기고, 프로그램이 처음 설정 화면과 함께 열려요.

2. 처음 설정

처음 켜면 아래 설정 창이 열려요. 나중에 다시 열려면 메인 화면 오른쪽 위 설정을 눌러요.

① 유튜브 채널 연결

유튜브 채널이 있는 구글 계정이면 따로 신청 없이 바로 로그인할 수 있어요.

  1. 로그인 — 구글 계정으로 로그인을 눌러요. 브라우저가 열려요.
  2. 계정 고르기 — 영상을 올릴 채널의 구글 계정을 골라요.
  3. "Google에서 확인하지 않은 앱" 화면 — 왼쪽 아래 고급을 누르고, 맨 아래 REC UPLOADER(으)로 이동(안전하지 않음)을 눌러요. 구글 심사를 받지 않은 개인 프로그램이라 나오는 화면이에요. 로그인 정보는 이 PC에만 저장돼요 (개인정보처리방침).
  4. 채널 고르기 — "계정 또는 채널 선택" 화면이 나오면 영상을 올릴 채널을 골라요. (채널이 브랜드 계정이면 여기서 꼭 골라야 해요)
  5. 권한 허용 — 모두 허용하고, "로그인됐어요" 문구가 보이면 브라우저를 닫아도 돼요.
로그인이 안 끝나거나 브라우저를 닫아 버렸다면 같은 버튼(다시 시도)을 다시 누르면 새 로그인 창이 열려요.

② 녹화 폴더 고르기

찾아보기…를 눌러 OBS 등 방송 프로그램이 녹화 파일을 저장하는 폴더를 골라요. OBS라면 설정 → 출력 → 녹화 → 녹화 경로에 적힌 폴더예요. 그 안에 썸네일 폴더가 자동으로 생겨요.

③ 기본 업로드 방식

항목설명
공개 범위새 영상의 기본 공개 범위예요. 영상마다 따로 바꿀 수도 있어요. 처음엔 비공개나 일부 공개로 두고 확인한 뒤 공개로 바꾸는 걸 권해요.
재생목록올린 영상을 넣을 재생목록이에요. 영상마다 따로 고르거나 "넣지 않음"으로 할 수 있어요.
방송(녹화) 중 업로드멈춤(권장): 녹화가 끝날 때까지 멈췄다가 이어서 올려요.
속도 제한: 초당 적은 양만 올려요.
그대로: 업로드 속도가 아주 넉넉할 때만 고르세요.
윈도우를 켜면 자동으로 실행PC를 켜면 트레이(시계 옆)에서 조용히 폴더를 감시해요.
영상 설명모든 영상에 들어갈 설명이에요. 비워도 돼요. 카테고리·태그는 보내지 않아서 채널 기본값이 쓰여요.

저장을 누르면 끝이에요. 연결이 끝나면 이렇게 보여요.

3. 썸네일 준비

녹화 폴더 안의 썸네일 폴더에 영상 파일과 같은 이름의 이미지를 넣으면 자동으로 짝지어져요.

📁 D:\방송 녹화 ├─ 🎞 2026-10-10 20-58-40.mp4 ├─ 🎞 2026-10-11 21-03-12.mp4 └─ 📁 썸네일 ├─ 🖼 2026-10-10 20-58-40.jpg ← 2026-10-10 20-58-40.mp4 의 썸네일 └─ 🖼 2026-10-11 21-03-12.png ← 2026-10-11 21-03-12.mp4 의 썸네일
  • jpg · png · webp 모두 돼요. 2MB가 넘거나 webp면 프로그램이 알아서 JPEG로 줄여 올려요.
  • 이름 맞추기가 번거로우면 카드의 썸네일 지정…으로 아무 이미지나 골라도 돼요.
  • 썸네일은 올리기 전까지 언제든 넣거나 바꿀 수 있어요. 카드에 바로 미리보기가 떠요.
자동 업로드는 썸네일이 있는 영상만 올려요. 썸네일 없이 올리고 싶으면 카드의 업로드를 직접 누르세요.

4. 화면 둘러보기

  1. 1
    연결된 채널 — 채널 이름과 다시 로그인까지 남은 날. 하루 남으면 노랗게 바뀌어요.
  2. 2
    설정 — 처음 설정 창을 다시 열어요 (로그인, 녹화 폴더, 업로드 방식). 옆의 사용설명서는 이 설명서를, 개선 의견은 의견 보내는 신청서를 열어요.
  3. 3
    녹화 폴더 · 썸네일 폴더 — 지금 감시 중인 폴더예요. 마우스를 올리면 전체 경로가 보여요.
  4. 4
    폴더 감시 중 — 초록이면 정상. 폴더를 찾을 수 없으면 노랗게 알려요.
  5. 5
    자동 업로드 스위치 — 켜면 녹화가 끝나고 썸네일까지 있는 영상을 오래된 것부터 바로 올려요.
  6. 6
    준비된 영상 모두 올리기 — 준비된 영상을 오래된 것부터 차례로 올려요.
  7. 7
    새 녹화본 · 올라간 영상 — 왼쪽은 아직 안 올린 녹화본(카드), 오른쪽은 유튜브에 올라간 영상 목록이에요.
  8. 8
    불러오기 — 날짜·재생목록을 바꾸면 버튼이 깜빡여요. 눌러야 목록이 바뀌어요.

5. 녹화본 카드와 상태

녹화 파일 하나가 카드 하나예요. 올리기 전에 제목·공개 범위·재생목록을 카드에서 바로 고쳐요.

  1. 1
    상태 — 아래 표를 보세요.
  2. 2
    유튜브 제목 — [녹화 날짜] 파일 이름으로 채워 둬요. 방송 제목으로 자유롭게 고치세요(최대 100자). 고치지 않아도 그대로 올라가요.
  3. 3
    공개 범위 — 이 영상만 다르게 할 때. "기본 설정 따르기"면 설정의 공개 범위를 써요.
  4. 4
    재생목록 — 이 영상만 다른 재생목록에 넣거나 넣지 않을 때.
  5. 5
    업로드 — 이 영상을 지금 올려요. 더 오래된 녹화본이 남아 있으면 함께 올릴지 물어봐요.
  6. 6
    썸네일 지정… — 썸네일 이미지를 직접 골라요. 썸네일이 없으면 노란 테두리로 보여요.
  7. 7
    제외 — 올리지 않을 녹화본을 목록에서 빼요. 아래 "제외한 녹화본 보기"에서 언제든 되돌릴 수 있어요.

상태별 의미

표시뜻
● 녹화 중OBS가 아직 파일을 쓰고 있어요. 이 파일은 건드리지 않아요.
● 녹화 끝남 · 확인 중파일 크기가 1~2분 그대로인지, 영상으로 잘 읽히는지 확인하고 있어요.
● 준비됨올릴 수 있어요. 자동 업로드가 켜져 있으면 곧 올라가요.
● 준비됨 · 썸네일 없음올릴 수는 있지만 자동 업로드는 하지 않아요. 썸네일을 넣거나 직접 업로드하세요.
● 업로드 대기 / 업로드 중차례를 기다리거나 올리는 중이에요. 진행률·속도·남은 시간이 보여요.
● 업로드 일시 정지방송(녹화) 중이라 멈췄어요. 녹화가 끝나면 멈춘 곳부터 이어서 올려요.
● 업로드 완료올라갔어요. 하루 동안 목록에 남고 유튜브에서 열기로 스튜디오를 열 수 있어요.
● 실패카드에 이유가 빨간 글씨로 나와요. 다시 시도를 눌러요.
● 영상으로 읽을 수 없음녹화가 비정상으로 끝나(전원·OBS 강제 종료 등) 파일이 깨졌어요.

6. 유튜브에 올리기

올리는 방법은 세 가지예요. 어느 방법이든 녹화가 오래된 것부터 올라가서 채널에 방송 순서대로 쌓여요.

카드의 업로드 버튼

한 영상만 올릴 때 써요. 그보다 오래된 녹화본이 아직 안 올라갔으면 이렇게 물어봐요.

준비된 영상 모두 올리기

준비된 영상을 모두 차례로 올려요. 썸네일 없는 영상이 섞여 있으면 먼저 알려 줘요.

자동 업로드

켜 두면 방송이 끝나고 녹화 확인이 끝나는 대로 썸네일이 있는 영상을 바로 올려요. 방송 끝나고 썸네일만 넣어 두면 끝이에요.

업로드가 끊겨도 괜찮아요. 인터넷이 끊기거나 PC를 꺼도, 다시 켜면 끊긴 곳부터 이어서 올려요.
유튜브는 하루에 올릴 수 있는 영상 수에 한도가 있어요. 한도를 넘으면 위쪽에 안내가 뜨고, 다음 날 한국 시간 오후 4~5시 이후에 자동으로 이어서 올려요.

7. 방송 중일 때

녹화가 시작되면 프로그램이 알아채고, 설정에 따라 업로드를 멈추거나 속도를 줄여요. 방송 화질이 떨어지지 않게 하기 위해서예요.

  • 방송 중인데도 꼭 올려야 하면 안내 띠의 지금 바로 올리기를 눌러요. 이번 녹화가 끝날 때까지 멈춤을 무시해요.
  • 멈추는 대신 속도만 줄이려면 설정 → 방송(녹화) 중 업로드 → 속도 제한을 골라요.

8. 올라간 영상 확인

  • 날짜별 / 재생목록별로 볼 수 있어요. 조건을 바꾸고 깜빡이는 불러오기를 눌러요.
  • 제목 수정 — 올라간 영상의 제목을 그 자리에서 고쳐요. Enter 저장, Esc 취소.
  • 열기 — 유튜브 스튜디오에서 그 영상을 열어요.
표시뜻과 할 일
유튜브 처리 중업로드는 끝났고 유튜브가 영상을 처리하고 있어요. 긴 방송은 몇 시간 걸릴 수 있어요. 기다리면 돼요.
처리 완료정상이에요.
⚠ 유튜브 처리 대기 N시간째4시간이 넘도록 처리가 안 끝났어요. 멈췄을 수 있어요. 스튜디오에서 확인하고, 멈춰 있으면 지운 뒤 다시 올리기.
소유권 주장으로 한국에서 차단됨음악·영상 저작권 때문에 한국에서 볼 수 없어요(빨간 칸). 스튜디오에서 해당 구간을 자르거나 이의 제기를 하거나, 지우고 다시 올려요. 다른 나라만 막힌 경우는 표시하지 않아요.
유튜브 처리 실패유튜브가 영상을 처리하지 못했어요. 지우고 다시 올려요.

다시 올리기

처리가 멈췄거나 막힌 영상의 파일이 이 PC에 남아 있으면 다시 올리기 버튼이 보여요. 누르면 확인 창이 떠요.

꼭 유튜브 스튜디오에서 먼저 그 영상을 지워 주세요. 지우지 않고 다시 올리면 같은 영상이 두 개가 돼요. 스튜디오 열기로 바로 열 수 있어요.

9. 로그인 유지

한 번 로그인하면 계속 유지돼요. 다시 로그인할 일은 이럴 때뿐이에요.

  • v0.6 이전에 로그인한 분 — 그때 받은 로그인은 7일 뒤 끝나요. 위쪽에 "다시 로그인까지 N일"이 보이면 설정 → 구글 계정으로 로그인을 한 번만 다시 눌러 주세요. 그 뒤로는 만료되지 않아요.
  • 구글 계정 비밀번호를 바꾸거나, 구글 계정 설정에서 이 프로그램의 권한을 지웠을 때
  • 로그인이 끊기면 위쪽에 빨간 안내와 다시 로그인 버튼이 떠요. 올리던 영상은 로그인하면 이어서 올라가요.

10. 트레이 · 자동 실행 · 업데이트

  • 창을 닫아도 꺼지지 않아요. 시계 옆 트레이에서 폴더 감시와 업로드를 계속해요. 트레이 아이콘을 누르면 창이 다시 열려요.
  • 완전히 끄려면 트레이 아이콘 우클릭 → 종료. 업로드 중이면 물어보고, 다음에 켜면 이어서 올려요.
  • 자동 실행은 설정의 "윈도우를 켜면 자동으로 실행"으로 켜고 꺼요.
  • 업데이트 — 새 버전이 나오면 오른쪽 위에 초록 업데이트 v… ● 버튼이 생겨요. 누르면 받아서 다시 켜요. 설정·기록·로그인은 그대로예요.

11. 자주 묻는 질문

로그인할 때 "Google에서 확인하지 않은 앱"이 나와요

정상이에요. 왼쪽 아래 고급 → REC UPLOADER(으)로 이동(안전하지 않음)을 눌러 계속하면 돼요. 이 프로그램은 서버 없이 PC에서만 동작하고, 로그인 정보는 PC에만 저장해요. 자세한 내용은 개인정보처리방침을 보세요.

로그인했는데 "채널이 없는 계정"이라고 해요

채널이 브랜드 계정에 있는 경우예요. 다시 로그인하면서 "계정 또는 채널 선택" 화면에서 영상을 올릴 채널을 골라 주세요.

방송이 끝났는데 계속 "녹화 끝남 · 확인 중"이에요

파일 크기가 1~2분 동안 변하지 않아야 끝난 것으로 봐요. OBS가 녹화를 마무리하는 중이거나, OBS가 아직 파일을 잡고 있으면 기다려요. OBS의 녹화 후 mp4로 변환을 쓰면 변환된 mp4만 목록에 나와요.

"영상으로 읽을 수 없음"이 떠요

녹화가 비정상으로 끝나 파일이 깨진 경우예요(전원 꺼짐, OBS 강제 종료 등). mkv로 녹화하면 이런 경우에도 대부분 살릴 수 있어요. 이 파일은 제외하세요.

올리던 중에 PC를 껐어요

괜찮아요. 다시 켜면 멈춘 곳부터 이어서 올려요.

녹화 파일이 지워지나요?

아니요. 올린 뒤에도 녹화 파일과 썸네일은 그대로 둬요. 필요 없으면 직접 정리하세요.

녹화 폴더를 바꾸면 예전 기록은요?

목록은 지금 고른 폴더의 녹화본만 보여 줘요. 예전 폴더의 기록은 지워지지 않고, 그 폴더로 돌아가면 다시 보여요.

프로그램을 지우고 싶어요

설정에서 "윈도우를 켜면 자동으로 실행"을 끄고 저장한 뒤, 트레이에서 종료하고 프로그램 폴더와 바탕화면 아이콘을 지우면 돼요. 로그인 정보도 그 폴더 안에만 있어서 함께 지워져요.

불편한 점이나 있으면 좋을 기능이 있나요? 프로그램 오른쪽 위 개선 의견(또는 트레이 메뉴의 "개선 의견 보내기")을 누르거나 개선사항 신청서에 남겨 주세요.
